What is inside

A notes app - not a tracker

Everything you need to write, find and reuse your reads on hundreds of opponents - without a single stat field, timer or hand-history engine.

⚡

Focus-first editor

Type and stay typing. There are no timers that create windows, no Topmost updates and no Activate() calls - the deferred save runs 1.2 s after your last keystroke and never touches focus.

🏷

Tags in your own colours

Create tags with a hex colour, tag players with one click, filter the player list by tag - and let the same colours frame the hover boxes on the table.

🔎

Aliases & instant search

Store every nick a player uses in one record. Ctrl+F searches the name, the aliases and the note text, so a read you wrote months ago is one keystroke away.

🗂

Note history & CSV export

Ctrl+E snapshots the current note with a timestamp (up to 40 per player) and loads any copy back into the editor. One click exports everything to Excel-ready CSV.

📸

Capture & hover boxes

Middle mouse button or one button press: the app finds your tables, reads the seat names with OCR and places a click-through box on every seat. Green = player in database, grey ? = new name.

🛡

Portable and private

One self-contained EXE, one plain JSON database, atomic saves and a .bak before every write. No installer, no admin rights, no network calls, no memory reading.

Zero setup: taking notes in 60 seconds

Poker Notes is a 100% self-contained portable application. There is no installer, no .NET runtime to download, no Python environment, no SQL server and no account to create.

  • 1
    Unzip the portable package
    Extract it anywhere - Desktop, a second drive or your poker tools folder. Keep Tesseract.dll, the tessdata\ folder and the x64\ DLLs next to the EXE; they are only used by the optional Capture & OCR features.
  • 2
    Run PokerVisionHUD.exe
    The app opens the database you used last; the path is remembered in %AppData%\PokerNoteManager_Settings.txt. So a fresh install starts with your existing notes already loaded.
  • 3
    Write the note and keep playing
    Pick a player in the left column - or press ＋ New player (Ctrl+N) and type the name exactly as the client shows it. The note saves itself about a second after you stop typing; saved HH:MM:SS next to the name confirms it.

💡 Pro-tip for multi-tablers

Set AUTO to 30 s or 1 min and the hover boxes follow players who come and go - without a single timer ever creating or activating a window. Boxes you removed yourself stay removed.

%AppData%\PokerNoteManager_Settings.txt

Write it, tag it, find it again

The editor is the whole workflow: one player record with tags, aliases, the note and its history. Nothing is ever written behind your back.

  • ✓
    Autosave & Ctrl+S: the note is saved about 1.2 seconds after your last keystroke, and only when something actually changed. Ctrl+S forces a save. Before every write the previous file is copied to <your-db>.json.bak.
  • ✓
    Tag chips: click a chip to add or remove a tag (filled = the player has it). 🏷 Tags opens the tag manager where you create tags and give each one a hex colour such as #FF8C00. Deleting a tag removes it from every player, after a warning.
  • ✓
    Filters & search: every tag also appears as a filter chip under PLAYERS. Ctrl+F jumps to the search box, which matches the player name, the aliases and the note text.
  • ✓
    Rename & delete: F2 renames the selected player - notes, tags, aliases and history follow. Delete asks first, and a .bak is always written before the change.

🏷 Where your colours live

Tags and their colours are stored in a small JSON file next to your settings, so your colour scheme survives a database switch. Left-over tag_<number> entries from the old HUD version are ignored instead of shown as garbage tags.

%AppData%\PokerNoteManager_Tags.json

Read the table, show the note

Screen reading is back in this release - rebuilt so it can never disturb your tables. There is no background scanning at all: images are only captured when you press the button.

  • ✓
    Pick the screen: the 📺 SCREEN selector at the top right chooses the monitor to look at (the choice is remembered). When you capture with the mouse, the screen under the cursor wins - handy when you run several tables.
  • ✓
    Capture & Scan: press 📸 Capture & Scan or the middle mouse button. Every window on that screen is checked for a green felt (browsers and lobbies are skipped, and a table without felt is judged by its window title), the seat names are read with OCR and one hover box is placed per seat. The status bar reports how many tables and names were found.
  • ✓
    Green box vs. grey box: a green box means the player is in your database - hover it and your tags and note appear in a card next to the mouse. A grey dashed box with a ? means the name was read but is not in the database yet.
  • ✓
    Ctrl+click to edit on the table: opens the note editor right there. Write, toggle tags with a click and save with the button or Ctrl+Enter. New names are created automatically and the old note is copied into the history. Esc or a click outside closes it. A normal click always goes through to the poker client, and right-click is never used (it folds on Unibet).
  • ✓
    Optional extras: 🗂 DB only: ON ignores names that are not in the database, tag colours frame the boxes, 👁 Boxes: ON/OFF hides the overlay, 🧹 Clear wipes it, 📋 Paste & Scan reads a screenshot from the clipboard and ✂️ Snip Player reads the name under the mouse.

🔍 Did OCR read the name wrong?

Use Ctrl+click or ✂️ Snip Player to correct the name once - afterwards the name matches reliably. Matching is tolerant of the classic OCR mix-ups (1/l/I, 0/O, 5/S, 8/B, 3/E) with a distance-based fallback, and the debug log lists every reading.

One player, many nicks, one place

Opponents rename themselves weekly. Aliases keep every nick attached to the same note instead of splitting your reads in two.

  • ✓
    Aliases: list the other nicks of a player separated by commas. Search matches aliases too, and the on-table note editor follows the same record.
  • ✓
    Note history: Save note copy (Ctrl+E) stores a timestamped copy of the current note. History lists them - pick one and press Load into editor, or Clear history to delete them. Up to 40 copies per player.
  • ✓
    CSV export: Export CSV writes one row per player with aliases, tags, the full note text and the number of history copies - semicolon separated with a UTF-8 BOM, so Excel opens it without any import dialog.
  • ✓
    Same player on two tables: every hover box belongs to its own table. The note is shared, but a box you remove with Ctrl+click disappears only on that table. The hover card shows e.g. ruhhy · at 2 tables and the status bar counts them.

🗂 Good notes beat more notes

Write one careful line per read - "calls down light", "min-raises nut draws", "folds to turn barrels" - and let tags do the sorting. The hover card shows the tags first and the note right after, so a read you wrote in June is still useful in December.

Your data, and where it lives

Everything is plain text and fully yours - no cloud, no account, no telemetry. Copy the database file to a USB stick and your notes travel with you.

  • ✓
    The database: a JSON file in the same format the HUD version wrote (version 1: players, tags, notes, note_history, aliases). Old stats and watch fields are ignored but preserved, so an old file opens unchanged and no note is lost.
  • ✓
    Safe saving: writes go to a temporary file that is then swapped in, and the previous version is kept as <your-db>.json.bak next to the database. Only one instance of the app runs at a time, so two copies can never overwrite each other.
  • ✓
    Settings & log: PokerNoteManager_Settings.txt (last database), PokerNoteManager_Tags.json (tags + colours) and PokerNotes_Window.txt (window size) live in %AppData%. The log %LocalAppData%\PokerVisionHUD\pokervision_debug.log rotates at 2 MB and opens straight from the ? menu.

What's new

The HUD left - the notes stayed

Poker Notes is the same program, rebuilt around the thing you actually used: your own reads. Here is exactly what changed, and why.

REMOVED

Live stat tracking

VPIP, PFR, 3-Bet, Fold-to-3-Bet, hand demarcation, action-badge watching, auto-tag rules, the watchlist and table calibration are gone. The database no longer writes a stats field.

Why: optical statistics drifted between sessions and themes - and a wrong number is worse than no number.
FIXED

Focus stealing - the real bug

The old build refreshed its HUD windows on a timer, forced them Topmost and activated them. That is exactly what took the cursor out of the notes field while you were typing.

Now: no timer creates or activates a window, the overlay cannot take focus (WS_EX_NOACTIVATE) and can only be brought forward with SWP_NOACTIVATE.
KEPT

Every note you ever wrote

An existing database opens unchanged: players, tags, notes, note history and aliases are read from the same version 1 JSON layout the HUD version wrote.

Bonus: the legacy stats and watch fields are preserved on disk instead of being thrown away.
NEW

Capture & hover boxes, rebuilt

The overlay is click-through (WS_EX_TRANSPARENT), so every click reaches the poker client. Boxes can be removed one by one and per table, plus DB-only mode, tag colours, Snapshot PNGs and an on-table note editor.

Also: multi-monitor and per-monitor DPI aware, window placement clamped to the screens that exist right now.
LEGACY

Nothing was taken away

Miss the numbers? The tracker build (PokerVision HUD v1.0) is kept as a separate backup, so the old live-stats version is still there whenever you want it.

Both programs read and write the very same .json database file.

Compliance Architecture

Why Poker Notes is TOS friendly

Classic trackers get flagged because they read or modify the memory of the poker client. Poker Notes never touches the client: it stores the text you write, and the optional capture only looks at a screenshot you asked for.

Security criterion Traditional poker HUDs Poker Notes (OpenPokerLab)
Memory reading (process hooks) ❌ Reads client RAM memory ✓ 0% memory reading - only your own notes
DLL injection / code modification ❌ Injects hooks into the poker client ✓ Zero code injection, no process access
Background scanning on a timer ⚠️ Polls the tables every 1-2 seconds ✓ No timers - capture only when you press it
Focus & input automation ⚠️ Can activate windows and click for you ✓ Click-through overlay that cannot take focus
Real-time assistance (RTA) ⚠️ Live solver output and strategy hints ✓ Only the plain text you wrote yourself
Privacy & data ownership ⚠️ Uploads hands and stats to cloud servers ✓ 100% local JSON file, zero network calls

Third-party tool policies differ from room to room - always check the current rules of the poker room you play on. Poker Notes is a manual note organizer: it never plays, clicks or decides for you.

Got Questions?

Frequently Asked Questions

Does Poker Notes still show live VPIP / PFR stats? ▼
No - and that is deliberate. The optical stat engine was removed in v2.0 because on-screen numbers drift with themes, bet sizes and skins: a wrong VPIP is worse than none, and the timer that refreshed them was exactly what stole focus while you were typing. Notes, tags, aliases and history all stay, and the old tracker build (v1.0) is kept as a separate backup download if you still want the numbers.
Do I need .NET, Python or an installer - and which rooms work? ▼
Nothing to install: the package is a self-contained portable EXE, runs without admin rights and needs no runtime, database server or account. It works with any client that draws the player names at the table - the window check simply skips browsers and lobbies that have no green felt. Just remember to keep Tesseract.dll, the tessdata\ folder and the x64\ DLLs next to the EXE if you want the optional Capture & OCR features.
Can it disturb my typing or my table while I play? ▼
No. There are no timers that create, activate or move windows, the hover overlay is click-through (WS_EX_TRANSPARENT) and can never take focus (WS_EX_NOACTIVATE), so every click lands in the poker client. The only background activity is the deferred save, which runs about 1.2 seconds after your last keystroke and only if something actually changed.
Is my old PokerVision HUD database still usable? ▼
Yes. Poker Notes reads and writes the same version 1 JSON layout, so an existing file opens unchanged with all players, tags, notes, aliases and note history. The legacy stats and watch fields are preserved on disk but no longer used, and a .bak copy of the previous file is written before every save.
Can I share or move my player database? ▼
Yes - it is a single plain .json file. Send it to a friend, drop it in Dropbox or open it with 📂 Open DB and keep several databases side by side. Prefer a spreadsheet? Export CSV writes every player with aliases, tags, notes and history count in an Excel-ready format.
What if the OCR reads a name wrong? ▼
Fix it once with Ctrl+click on the box or ✂️ Snip Player - after that the name matches reliably. Matching tolerates the classic OCR mix-ups (1/l/I, 0/O, 5/S, 8/B, 3/E) plus a distance-based fallback, and the box turns grey with a ? instead of guessing when a name is unknown. 🔎 Snapshot saves the captured table with the readings, ready to send along if something looks odd.
Is there a version that needs no download at all? ▼
Yes - the browser-based Note Manager on this site covers the same idea with tabs, tags and local storage. Poker Notes is the desktop version: faster to reach while you play, with many more players, aliases, history, CSV export and the OCR hover boxes.
